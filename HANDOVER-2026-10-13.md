## Running it

- App: `http://127.0.0.1:8101/v2/`. Start from `D:\cloud lens v3` with
  `C:\Users\raviverma\.venvs\cloudlenstony\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8101 --log-level warning`
  and `CLOUDLENS_MANAGED_EXPORTS=false`. Wait for `/readyz` to return `{"status":"ready"}`.
- Stop it by killing the listener and its launcher by PID. Resolve the PIDs first.
- UI: `cd ui; npm test` (149 tests, about two minutes) and `npm run build`. The UI suite is
  timing-sensitive under load; re-run a failure alone before believing it.
- Backend: set `CLOUDLENS_PG_TEST=localhost`, `CLOUDLENS_PG_USER=postgres`, `PGPASSWORD` from `.env`,
  `PGSSLMODE=disable`, then `python -m pytest -q`. Lint with `python -m ruff check app/`.
