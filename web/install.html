Option 2 · Guided setup

PowerShell installer

Release not published. The GitHub release v2026.11.12-rc5 and its source ZIP/checksums are not published. The default command below cannot complete installation until the release is available. Downloading this bootstrap does not make the release available.

Use PowerShell 7 with Azure CLI and Python 3.11+. Review the downloaded script before running it. The guided installer verifies the source archive, previews changes and requests approval.

Already have an approved offline archive? The downloaded script supports -SourceZip and a separately verified -SourceSha256. Contact your release owner for both; do not bypass verification. For infrastructure already created in the portal, use -Resume with the same subscription, resource group and deployment parameters.

Before you deploy

  • Choose an approved subscription, regions and budget. Web app, PostgreSQL, storage and AI resources incur charges.
  • Confirm resource creation and role-assignment permissions: usually Owner, or Contributor plus User Access Administrator.
  • Arrange Microsoft Entra administrator approval for sign-in setup; subscription Owner alone does not grant this.
  • Review the template and installer. Never paste passwords, access tokens or private configuration into this page.
